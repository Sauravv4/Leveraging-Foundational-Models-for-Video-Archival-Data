# Reference material for the write-up

Everything in this folder is **reference only** — it is not part of the pipeline
and nothing in `src/` imports from here. It exists so that the research paper
and the supporting-materials report for this project can be written against
known-good exemplars and the correct template.

## Contents

| Path | What it is |
|------|------------|
| `ieee-conference-template-letter.docx` | Official IEEE conference template (US Letter). The paper must be authored in this file / with these styles. |
| `exemplars/exemplar-A_research-paper_wind-turbine-VFM.pdf` | MSc AI research paper — *Fine-Grained Vision Foundation Models for Automated Wind Turbine Inspection* (40356093). Vision-foundation-model project; closest domain match to this one. |
| `exemplars/exemplar-A_supporting-materials_wind-turbine-VFM.pdf` | Matching supporting-materials report for exemplar A. |
| `exemplars/exemplar-B_research-paper_clinical-LLM-extraction.pdf` | MSc AI research paper — clinical LLM information extraction (40494685). Strongest example of explicit RQ-driven structure. |
| `exemplars/exemplar-B_supporting-materials_clinical-LLM-extraction.pdf` | Matching supporting-materials report for exemplar B. |
| `exemplars/text/*.txt` | Plain-text extractions of the four PDFs (PyMuPDF), so sections can be grepped without re-parsing. |

## How to use them

Read `../WRITING_GUIDE.md` — it distils the two exemplars into a section-by-section
plan for this project, with word budgets and the IEEE style names to apply.

**Use these for structure, argument shape and level of rigour — not for prose.**
They are other students' submitted work. Do not reuse sentences, tables or figure
designs from them, and do not cite them as sources; their value is as a model of
what a passing ECS8056-style submission contains and how claims are evidenced.

> These are third-party submissions containing the authors' names and student
> numbers. Keep this repository private, or strip this folder before making it
> public.
